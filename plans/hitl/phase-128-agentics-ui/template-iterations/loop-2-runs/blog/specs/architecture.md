## Site class: content-driven

## Stack
Astro 4 — zero-JS by default, target LCP ≤1.5 s, ~30 KB initial JS. Tailwind CSS 4.0 (JIT mode).

## Routing & rendering
MPA static routes. All content (articles, hero, newsletter) SSG. Navigation collapses at `breakpoint-md` (768px).

## Hosting & build
Cloudflare Pages — global CDN for optimal LCP. `build` command: `npm run build`, output dir: `dist`. Edge.

## Integrations
*   Formspree: `@formspree/react` 2.5.1. Fallback: browser default form submission with basic validation.
*   Plausible Analytics: `plausible-tracker` 0.5.9. Fallback: none (non-critical).
*   Cloudinary: `@cloudinary/html` 1.3.1. Fallback: raw image hosting.

## Runtime states
*   Newsletter signup: { idle, submitting, success-200, fail-4xx, fail-5xx, network-timeout }. Button disabled during `submitting`. Success message fades after 3s. Error message persists until user input or dismiss.

## Quality budgets
LCP target: ≤1500 ms
INP target: ≤200 ms
CLS: ≤0.1
Initial JS: ≤30 KB
WCAG level: 2.2 AA
Reduced-motion: yes
Focus ring: yes

## SEO & social
Title pattern: `[Article Title] | Hey Bradley` or `Hey Bradley - [Tagline]`
Meta description rule: Max 160 chars, either article excerpt or site tagline.
OG image strategy: Default image for site, specific image for articles (Cloudinary optimized).
JSON-LD types: `Article`, `Organization`, `BreadcrumbList`.
sitemap.xml: Auto-generated by Astro.
robots.txt: Disallow `/admin`, allow `/`.
