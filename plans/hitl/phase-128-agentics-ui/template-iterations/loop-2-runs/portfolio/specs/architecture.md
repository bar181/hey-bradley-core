## Site class: static-brochure

## Stack
Astro 4 — zero-JS by default, target LCP ≤1.5 s, ~30 KB initial JS. Tailwind CSS 4.

## Routing & rendering
MPA static routes. All routes SSG. Navigation collapses at 768px (md).

## Hosting & build
Cloudflare Pages — global CDN, good for static assets. Build command: `npm run build`. Output directory: `dist`. Edge deployment.

## Integrations
*   YouTube Embed (native iframe)
*   Plausible Analytics 2.x – `data-domain` attribute for privacy-friendly analytics.
*   Cloudinary (optional for image optimization, if needed for performance or dynamic resizing outside build)

## Runtime states
None (static site).
