## Site class: static-brochure

## Stack
Astro 4 — zero-JS by default, target LCP ≤1.5 s, ~30 KB initial JS. Tailwind CSS 4.

## Routing & rendering
MPA static routes. All routes SSG. Navigation collapses at `md` breakpoint (768px).

## Hosting & build
Cloudflare Pages — global CDN, good build performance for static sites.
Build command: `astro build`
Output dir: `dist`
Edge.

## Integrations
*   Formspree: `@formspree/react@2` (for contact forms). Fallback: mailto link.
*   Plausible Analytics: `plausible-tracker@0.4`. Fallback: None (optional analytics).
*   Cloudinary: Image CDN for optimized images. Fallback: self-hosted optimized static images.
*   Resend: `resend@3` (for backend form submissions to email). Fallback: Formspree direct.

## Runtime states
*   **Contact Form:**
    *   `idle`: Initial state.
    *   `submitting`: Form data being sent.
    *   `success-200`: Submission successful, display confirmation.
    *   `fail-4xx`: Client-side error (e.g., validation), display specific error.
    *   `fail-5xx`: Server-side error, display generic error.
    *   `network-timeout`: Request timed out, display network error.
*   **Navigation Menu (Mobile):**
    *   `closed`: Default state.
    *   `open`: Menu expanded.
    *   `animating-in`: Transition to `open`.
    *   `animating-out`: Transition to `closed`.

## Quality budgets
*   LCP target: ≤ 1000 ms
*   INP target: ≤ 200 ms
*   CLS: ≤ 0.05
*   Initial JS: ≤ 20 KB
*   WCAG level: 2.2 AA
*   Reduced-motion respected: yes
*   Focus ring visible: yes

## SEO & social
*   Title pattern: `[Page Title] | Atlas AI Consulting`
*   Meta description rule: Max 160 characters, relevant keywords. Default: "Expert AI consulting for strategic implementation, development, and training to transform your business."
*   OG image strategy: Default `og:image` from `public/og-image.jpg`, specific for key pages.
*   JSON-LD types: `Organization`, `WebSite`.
*   sitemap.xml: auto-generated by Astro.
*   robots.txt: Disallow `/admin/*`, `Allow: /`.
