## Site class: static-brochure

## Stack
Astro 4 — zero-JS by default, target LCP ≤1.5 s, ~30 KB initial JS. Styling with Tailwind CSS 4.

## Routing & rendering
MPA static routes. All pages SSG. Navigation collapses at 768px (`md` breakpoint).

## Hosting & build
Vercel — optimized for Astro SSG, global CDN. Build command: `astro build`. Output directory: `dist`. Edge hosting.

## Integrations
*   Google Fonts API v2 (for Inter, Outfit) — fallback to system UI fonts.
*   YouTube/Vimeo Embed — `<lite-youtube>` or `<lite-vimeo>` web component for performance.
*   Cloudinary - Image CDN for project images, `q_auto,f_auto` optimization.
*   Plausible Analytics — `plausible.js` script.

## Runtime states
None. All content is static.

## Quality budgets
*   LCP target: ≤1200 ms
*   INP target: ≤200 ms
*   CLS: ≤0.05
*   Initial JS: ≤30 KB
*   WCAG level: 2.2 AA
*   Reduced-motion respected: yes
*   Focus ring visible: yes

## SEO & social
*   Title pattern: `{Page Title} | Bradley Ross | Visual Designer`
*   Meta description rule: `Visual design portfolio of Bradley Ross, showcasing thoughtful visual experiences.`
*   OG image strategy: Default `og:image` pointing to a pre-rendered hero image of Bradley Ross with text overlay.
*   JSON-LD types: `Organization`, `Person` (for Bradley Ross), `WebSite`.
*   `sitemap.xml`: auto-generated by Astro.
*   `robots.txt`: Disallow `/cdn-cgi/`.
