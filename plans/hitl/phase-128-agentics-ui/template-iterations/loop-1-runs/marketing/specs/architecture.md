## Site class: static-brochure

## Stack
Astro 4 — zero-JS by default, target LCP ≤1.5 s, ~30 KB initial JS. Tailwind CSS 4.

## Routing & rendering
MPA static routes. All pages SSG. Navigation collapses at `min-width: 768px`.

## Hosting & build
Cloudflare Pages — global CDN for SSG, free SSL, good DX for Git integration.
Build command: `astro build`
Output dir: `dist`
Edge.

## Integrations
*   Formspree (latest) — email form submission for contact sections. Fallback: `mailto:` link.
*   Plausible Analytics (latest) — privacy-focused analytics. Fallback: None (client-side script).
*   Cloudinary (latest) — image optimization and delivery. Fallback: self-hosted optimized images.

## Runtime states
*   Newsletter signup (if added): { idle, submitting, success-200, fail-4xx, fail-5xx, network-timeout }
*   Contact Form: { idle, submitting, success-200, fail-4xx, fail-5xx, network-timeout }
