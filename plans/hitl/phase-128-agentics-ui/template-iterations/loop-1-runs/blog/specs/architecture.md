## Site class: content-driven

## Stack
Astro 4 — zero-JS by default, target LCP ≤1.5 s, ~30 KB initial JS. Tailwind CSS 4.

## Routing & rendering
MPA static routes. All content SSG.
Navigation collapses to hamburger menu at `960px` (md breakpoint).

## Hosting & build
Cloudflare Pages — global CDN, DDoS protection, edge functions for forms.
Build command: `astro build`
Output dir: `dist`
Edge.

## Integrations
* Formspree/react 2.2.0 — newsletter signup form handler.
* Umami 1.4.0 — analytics, self-hosted option.
* Cloudinary/react 1.11.0 — image CDN, responsive images, format optimization.
* Resend 3.2.0 — transactional emails for form confirmations.

## Runtime states
* Newsletter signup:
  * `idle`: Initial state, input visible.
  * `submitting`: Form disabled, spinner visible.
  * `success-200`: Success message, input cleared/hidden.
  * `fail-4xx`: Error message ("Invalid input, please try again.").
  * `fail-5xx`: Error message ("Service unavailable, please try again later.").
  * `network-timeout`: Error message ("Network error, please check your connection.").

## SEO & social
Title pattern: `[Article Title] | Hey Bradley` or `[Section Name] | Hey Bradley`
Meta description rule: First 150-160 characters of article body, or static description for main pages.
OG image strategy: Default brand image, or article-specific image if available.
JSON-LD types: `Article`, `Organization`, `BreadcrumbList`.
sitemap.xml + robots.txt: Auto-generated by Astro, respects `noindex` where specified.
