## Site class: content-driven

## Stack
Astro 4 — zero-JS by default, target LCP ≤1.5 s, ~30 KB initial JS. Tailwind 4.

## Routing & rendering
MPA static routes. All pages SSG. Navigation collapses at `min-width: 768px`.

## Hosting & build
Cloudflare Pages — fast global CDN, generous free tier.
Build command: `astro build`
Output directory: `dist`
Edge deployment.

## Integrations
*   Formspree `^2.5.0` — newsletter form handler. Fallback: browser `mailto:` link.
*   Plausible `^2.2.0` — privacy-focused analytics. Fallback: none (non-essential).
*   Cloudinary `^2.1.0` — image optimization and delivery for `author-bio-01` image. Fallback: raw image served from static assets.

## Runtime states
*   Newsletter signup:
    *   `idle`
    *   `submitting`
    *   `success-200` (message: "Thanks for subscribing!")
    *   `fail-4xx` (message: "Something went wrong. Please try again.")
    *   `fail-5xx` (message: "Our servers are busy. Please try again later.")
    *   `network-timeout` (message: "Network error. Check your connection.")

## Quality budgets
*   LCP target: 1500 ms
*   INP target: 200 ms
*   CLS: 0.05
*   Initial JS: 30 KB
*   WCAG level: 2.2 AA
*   Reduced-motion respected: yes
*   Focus ring visible: yes

## SEO & social
*   Title pattern: `{Page Title} | Hey Bradley`
*   Meta description rule: First 160 characters of article content for content pages, site tagline for homepage.
*   OG image strategy: Default `og-image.jpg` from static assets, specific article image for content pages.
*   JSON-LD types: `Article` (for content pages), `Organization`, `BreadcrumbList`.
*   `sitemap.xml`: auto-generated by Astro.
*   `robots.txt`: allows all (`User-agent: * Allow: /`).
