## Site class: static-brochure

## Stack
Astro 4 — zero-JS by default, target LCP ≤1.5 s, ~30 KB initial JS. Tailwind CSS 4.

## Routing & rendering
MPA static routes. All routes SSG. Navigation collapses to hamburger menu at `992px`.

## Hosting & build
Cloudflare Pages — global CDN, good for static assets.
Build command: `astro build`
Output dir: `dist`
Edge.

## Integrations
*   Google Fonts: Inter@400,500,700, Outfit@700 (self-hosted for performance).
*   YouTube Embed: iframe with `loading="lazy"` attribute.
*   Image CDN: raw (no external image CDN needed for a portfolio with limited, curated images).

## Runtime states
No interactive components beyond navigation.

## Quality budgets
LCP target: 1500 ms
INP target: 200 ms
CLS: 0.05
Initial JS: 0 KB (excluding Astro island hydration if explicitly added, none expected)
WCAG level: 2.2 AA
Reduced-motion: yes
Focus ring: yes

## SEO & social
Title pattern: `{{page.title}} | Bradley Ross` (e.g., "Home | Bradley Ross").

sitemap.xml: Auto-generated by Astro.
