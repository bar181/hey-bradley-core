## Bounded contexts
1.  **Navigation** — Manages site-wide persistent menu and intra-page links.
2.  **Hero Display** — Presents the primary introductory content and call to action.
3.  **Media Embed** — Displays external video content (e.g., design reel).
4.  **Project Showcase** — Organizes and renders individual project cards in a grid layout.
5.  **Contact Information** — Provides direct links for professional outreach.

## Data flow
User Entry → Navbar → Hero (Intro/CTA) → Video Reel → Project Grid (Project Cards) → Contact Links
