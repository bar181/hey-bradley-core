— 03 / The protocol

AISP — five atoms that close the gap between human intent and machine execution.

01
— GOAL
Ω
What to build
The terminal outcome. Single sentence. No verbs you wouldn't say to a CFO.
02
— SHAPE
Σ
Exact format
Layout, density, breakpoints, schema. No prose. Only resolvable tokens.
03
— RULES
Γ
Forbidden
What this build is not. Scoped negatives. Constrains the model space.
04
— HOW
Λ
Steps
Deterministic state transitions. Every interaction has one resolved path.
05
— VERIFY
E
Proof
Acceptance tests + ambiguity score δ. No spec ships above 0.02.
Ω∧Σ∧Γ∧Λ⊢E
— if all four upstream atoms resolve, the proof is deterministic. ambiguity collapses to δ < 0.02.
