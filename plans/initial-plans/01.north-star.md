## 1. VISION

> **"A whiteboard that listens, builds what you describe in real-time, and secretly writes enterprise specs behind the scenes."**

Hey Bradley is a JSON-driven marketing website specification platform. It produces two outputs simultaneously: a live visual preview the user interacts with, and enterprise-grade AISP specification documents the user exports. It is **not** a website builder competitor — it is a specification platform that feeds builders, dev tools, and agentic pipelines.

### 1.1 Pipeline Position

```
Ideation → Hey Bradley → Specs + JSON → Claude Code / Agentic System → Production Site
```

### 3.1 POC Success (Capstone Demo)

The primary success factor is **wow factor**. This is a Harvard capstone project reviewed by an expert UI designer. The bar: "This looks like a funded startup product, not a student project."

| Criterion | Target |
|-----------|--------|
| Time to first meaningful result | < 30 seconds (click vibe → see website) |
| Mode switching (DRAFT ↔ EXPERT) | Instant, smooth, no data loss |
| Listen Mode visual impact | "The dark screen with the glowing red orb" |
| Spec output quality | Pasting into Claude Code produces matching site |
| Design quality | Indistinguishable from Framer/Linear/Vercel's UI |

### 3.2 The "Aha!" Moments (Ordered)

1. **Click a vibe → website appears** (DRAFT mode, 2 seconds)
2. **Toggle to EXPERT → full property inspector appears** (same data, more control)
3. **Toggle to LISTEN → theatrical dark mode with red orb** (wow factor)
4. **Click DATA tab → see the JSON that drives everything** (engineering credibility)
5. **Click XAI DOCS → see AISP specs auto-generated** (invisible documentation)
6. **Click WORKFLOW → see the AI pipeline in action** (XAI transparency)

- **5-atom AISP Crystal Atom architecture** (INTENT/ASSUMPTIONS/SELECTION/CONTENT/PATCH) — superseded the original "spec documents" framing with a deterministic neuro-symbolic pipeline (ADR-053/057/060/064/045)

- **Personality engine** (5 modes, Option B composition, ADR-073)
- **Sprint K-O moat sequence:** Speed visible, Spec unmissable, Premium templates, Shareable output (in-browser stub), Open Core RC `v1.0.0-RC1`
- **17 example sites · 16 section types · 12 themes · 84+ ADRs · 392+ PURE-UNIT GREEN**
- **Competitive position:** 61/80 vs Lovable 51, Claude Designer 46, Framer 45 (`tests/p60-competitive-analysis.md`)

### 5.2 Open-core scope additions (P61 launch plan)

These ride on top of v3.0 PMF, not replacing it:

- **Multi-page MVP** — ADR-085. Per-page AISP spec generation. NOT in v3.0; promoted to launch-blocking because single-page-only is HB's weakest competitive dimension.
- **Process pages content type** — ADR-086 (a). Static methodology pages. New template category. Open-core compatible.
- **Agentic-product templates** — ADR-086 (b). Templates FOR agentic products (AI agent landing pages, dashboard SaaS marketing). NOT live agents — open-core stays static-output.
- **Mobile redesign** — single-mode chat with listen toggle. Supersedes the Sprint J P53 3-tab nav (ADR-076 → ADR-087 pending). **X8 stands** for builder authoring; consumed-mode mobile UX is in scope.

### 5.3 Hard Tier-2 boundary (commercial-only, NOT open-core)
