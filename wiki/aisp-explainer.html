💡 What Is AISP?

AI Symbolic Protocol is an open standard that replaces natural language with precise mathematical notation drawn from formal logic, type theory, and category theory. Think of it as a specification language for knowledge — every document has exactly one parse tree, every symbol has exactly one meaning, and every document carries its own proof of well-formedness.

Where natural language is ambiguous (“the bank” — river or financial?), AISP’s 512 symbols have fixed, context-independent meanings. Where code is partially ambiguous (5–15%), AISP achieves below 2%. This matters because ambiguity compounds: a 10-step pipeline with 90% per-step accuracy has only 35% end-to-end success. With 99.5% per-step accuracy, the same pipeline hits 95%.

AISP is implemented in pure Rust with 48 workspace crates, zero external ML dependencies, and nanosecond-level inference. It is the foundation layer for the fractal knowledge architecture.

🧩 Pocket Architecture: Content-Addressed Knowledge

Every AISP node (called a “pocket”) has three layers. The Header and Nucleus are immutable — sealed by SHA-256. The Membrane is mutable — it learns without changing the node’s identity. This is the foundation of deterministic AI: content determines identity, and identity never drifts.

Tamper = automatic rejection. If anyone modifies a pocket’s Nucleus, the SHA-256 hash changes, and every reference to that pocket breaks. No manual audit needed — the math enforces integrity (Theorem T3).
