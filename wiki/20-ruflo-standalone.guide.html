What Is Ruflo

One command. Sixty agents.
Zero configuration drift.

Ruflo (formerly Claude-Flow) is an open-source platform by Reuven Cohen that transforms a single Claude Code instance into a distributed multi-agent development environment. Instead of prompting one AI and hoping it gets everything right, you deploy a swarm — specialized agents that divide, coordinate, and conquer complex tasks in parallel.

The agents don’t just work side by side. They share memory, reach consensus on decisions, learn from outcomes, and coordinate through topology-aware communication. The result is an AI team that operates like a well-run engineering organization.

Developer Guide — Step by Step

From zero to swarm in 10 minutes.

1

Install Ruflo

Install globally via npm, or run with npx for zero-install usage.

# Global install npm install -g ruflo # Or zero-install with npx npx ruflo@latest --help
2

Initialize Your Project

Run the init wizard in your project root. Creates .swarm/ directory with config and memory database.

# Interactive setup npx ruflo init --wizard # Or with specific options npx ruflo init --topology hierarchical --max-agents 8
3

Connect to Claude Code via MCP

Register Ruflo as an MCP (Model Context Protocol) server. This gives Claude Code access to all Ruflo tools natively.

# Add as MCP server claude mcp add ruflo -- npx -y @claude-flow/cli@latest # Verify connection npx ruflo mcp status
4

Start the Daemon

The daemon runs background workers for hooks, memory consolidation, and session persistence.

# Start background services npx ruflo daemon start # Check everything is healthy npx ruflo doctor --fix
5

Initialize a Swarm

Create a coordinated agent swarm. Choose topology based on your task type.

# Hierarchical swarm (best for coding tasks) npx ruflo swarm init --topology hierarchical --max-agents 8 --strategy specialized # Check swarm status npx ruflo swarm status
6

Spawn Specialized Agents

Each agent type is pre-configured with domain-specific tools and knowledge.

# Spawn by type npx ruflo agent spawn -t coder --name my-coder npx ruflo agent spawn -t tester --name my-tester npx ruflo agent spawn -t reviewer --name my-reviewer # List running agents npx ruflo agent list # Check agent health npx ruflo agent health
7

Store & Search Memory

Agents share knowledge through HNSW-indexed vector memory. Patterns persist across sessions.

# Store a pattern npx ruflo memory store --key "auth-jwt" --value "JWT with refresh token rotation" --namespace patterns # Semantic search (finds by meaning, not just keywords) npx ruflo memory search --query "authentication session management" # List stored knowledge npx ruflo memory list --namespace patterns --limit 20 # Retrieve specific key npx ruflo memory retrieve --key "auth-jwt"
8

Enable Hooks

Lifecycle hooks fire automatically before/after tasks and edits. They handle linting, testing, pattern recording, and learning.

# Enable key hooks npx ruflo hooks enable --pre-task --post-task --post-edit # View hook explanations npx ruflo hooks explain # Check hook metrics npx ruflo hooks metrics
9

Use Hive Mind for Consensus

When agents need to agree on a decision (architecture, merge strategy, etc.), use hive-mind consensus.

# Initialize with Byzantine fault tolerance npx ruflo hive-mind init --strategy byzantine # Or use Raft for simpler leader-based consensus npx ruflo hive-mind init --strategy raft # Check consensus status npx ruflo hive-mind status
10

Orchestrate a Task

Give the swarm a task. The coordinator decomposes it, assigns to specialists, and synthesizes results.

# Create and assign a task npx ruflo task create --title "Implement user auth" --priority high npx ruflo task assign --id 1 --agent my-coder # Check task status npx ruflo task status # Full system overview npx ruflo status
Core Capabilities

Everything Ruflo does.

Multi-Agent Swarms

Deploy and coordinate 60+ specialized agents autonomously. Hierarchical, mesh, ring, star, hybrid, and adaptive topologies. Up to 50 concurrent agents per swarm.

swarm init agent spawn swarm status

HNSW Vector Memory

Persistent semantic memory with 150x–12,500x faster retrieval. Three tiers: working memory, episodic memory, semantic memory. Powered by AgentDB with HNSW indexing.

memory store memory search memory list

Self-Learning (SONA)

Self-Optimizing Neural Adaptation learns from every interaction. MicroLoRA for instant fine-tuning. ReasoningBank for trajectory tracking. EWC++ prevents catastrophic forgetting.

neural train neural predict neural patterns

Lifecycle Hooks

17 hooks + 12 background workers. Pre/post task, pre/post edit, session start/end. Automated linting, testing, pattern recording, and NightlyLearner consolidation.

hooks pre-task hooks post-edit hooks session-end

Hive Mind Consensus

Queen-led Byzantine fault-tolerant consensus. Three queen types (strategic, tactical, adaptive). Eight worker types. Raft, BFT, CRDT, and gossip protocols.

hive-mind init consensus raft bft

WASM Sandboxing

WebAssembly isolation for AI-generated code execution. No OS access, virtual filesystem, portable across platforms. BitNet 1.58-bit quantization with WASM acceleration.

wasm create wasm prompt wasm export

GitHub Integration

Native PR management, code review swarms, issue tracking, release automation, multi-repo coordination. 13 dedicated GitHub agent types.

pr-manager code-review release

MCP Native

Built for the Model Context Protocol. Every capability is exposed as an MCP tool. Seamless integration with Claude Code and any MCP-compatible client.

mcp status mcp tools config provider

Memory System — AgentDB

Three tiers of persistent intelligence.

Working Memory

Short-term, task-specific
  • Current task context
  • Active file states
  • In-progress decisions
  • Cleared after task completion

Episodic Memory

Medium-term, session-scoped
  • Interaction history
  • Success/failure outcomes
  • Agent routing decisions
  • Persists across conversations

Semantic Memory

Long-term, permanent
  • Learned patterns and strategies
  • Architectural knowledge
  • Code conventions
  • Protected by EWC++ from forgetting
